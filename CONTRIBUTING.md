# Contributing to WORLD

## Before changing files
- Keep the project name and story continuity intact.
- Keep MAYA, TESSA, and DogFightWar separate from this repository.
- Prefer focused changes and descriptive commit messages.
- Do not add generated Unreal build folders.

## Unreal assets
The Unreal Editor should generate native project files and binary assets. Do not hand-write fake .uasset or .umap files.

## Content and licensing
Use original or properly licensed assets. Record provenance in Docs/ASSET_INVENTORY.md.

## Platform support
Any gameplay or environment feature intended for Android must be tested against a real device and a documented performance budget.
