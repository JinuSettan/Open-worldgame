- Characters: Alex, Russell, Viktor, Maya, Victor Hale, civilian and faction NPCs

- Environment: buildings, roads, props, vegetation, terrain materials
- Weapons and mission props
- UI icons, audio, animation, VFX

## Import checklist
1. Confirm source and license.
2. Record original repository and path.
3. Inspect geometry and textures.
4. Verify scale and forward axis.
5. Check material assignments and texture sizes.
6. Create or verify collision.
7. Generate appropriate LODs / Nanite setup where suitable.
8. Test on PC and Android target profiles.
9. Keep original source files backed up.

## Git LFS
Large binary assets may require Git LFS. LFS bandwidth and storage quotas apply. Do not upload large model collections until the storage plan and asset licenses are confirmed.
