# Unreal Engine Project

This folder is reserved for the real Unreal Engine project.

Create the project in Unreal Editor on a supported Windows development environment, then place the generated project folder here as `Unreal/WORLD/`.

Do not create placeholder `.uproject`, `.uasset`, or `.umap` files by hand. Those files must be generated by Unreal Editor.

Planned project name: `WORLD`  
Planned engine: Unreal Engine 5  
Planned first region: San Veyra
